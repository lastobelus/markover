The Tiny Story

Imagine mailing a package. An ad-hoc signature is a tamper-evident strip you applied yourself: the recipient can see whether the box changed, but Apple does not vouch for who packed it. A Developer ID signature plus notarization is the same sealed box with a verified sender passport and Apple's automated inspection receipt.

We can build and test the first kind today. We should not pretend we have the second kind, nor add credential-dependent machinery we cannot exercise.

The trust system at a glance
