# Archived Markover logo and favicon explorations

This directory formerly contained the settled logo and favicon exploration:
eight concept boards, written prompt and decision notes, finalist and variation
studies, spacing-scale studies, SVG lockups, and local HTML indexes.

The complete original contents are preserved in the Git tag
`design-explorations-archive-2026-08-18`. To inspect them in a separate
worktree without changing the current checkout, run:

```sh
git worktree add ../markover-design-explorations design-explorations-archive-2026-08-18
```

The archived directory is then available at
`../markover-design-explorations/design/logo-explorations/`.
