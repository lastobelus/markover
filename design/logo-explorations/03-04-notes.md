# Markover logo explorations 03–04

Both boards were generated with the built-in image generation tool. They are
concept directions, not final production vector artwork.

## 03 — Swiss panes

![Swiss panes identity board](./03-swiss-panes.png)

### Rationale

The paired cobalt and red modules read first as comparison/review panes, then as
two document blocks. The red module's open folded corner introduces an edit or
handoff gesture without relying on a comment bubble or checkmark. Its simple
vertical silhouette and limited color split can be redrawn on a strict grid and
simplified further for a production favicon.

### Generation prompt

> Use case: logo-brand
>
> Asset type: clean brand identity concept board for a desktop Markdown review application
>
> Primary request: Design one original Markover logo system based on Swiss-modern split panes, a modular grid, and strong negative space. The core symbol should derive from reviewing/compare panes or a precise fold-over: two adjacent vertical modules with one crisp overlapping or turned corner that subtly implies a comment/review action. Make the symbol extremely ownable, geometric, compact, and readable at favicon scale—do not use a generic speech bubble or generic letter M.
>
> Scene/backdrop: perfectly flat warm-white presentation board, no environmental scene and no mockups.
>
> Subject: Show exactly three coordinated components with generous whitespace: (1) large standalone symbol, (2) horizontal lockup pairing the same symbol with the exact wordmark “Markover”, and (3) a favicon/app-icon crop of the symbol inside a simple square container. Keep all three visibly identical as one identity system.
>
> Style/medium: pristine 2D flat vector-logo aesthetic, Swiss International Typographic Style, modular construction, exact optical alignment, rational geometry, restrained modern grotesk wordmark. No gradients, shadows, depth, bevels, textures, or photorealism.
>
> Composition/framing: landscape identity board, three clear zones, strict invisible grid, generous margins; large symbol on left, horizontal lockup prominent through center, favicon specimen at right; no annotations or additional labels.
>
> Color palette: saturated cobalt blue, signal red accent used sparingly, warm white, deep black. Limit to these colors.
>
> Text (verbatim): “Markover” — render exactly once, spelled M-a-r-k-o-v-e-r, with no tagline and no other text.
>
> Constraints: flat vector-friendly shapes; high-contrast silhouette; strong negative space; visually balanced at 16 px; one coherent symbol repeated consistently; exacting, rational, contemporary, suited to a compact Electron developer tool.
>
> Avoid: stationery, devices, office mockups, paper mockups, business cards, UI screenshots, multiple competing logo options, hexagons, checkmarks, eye icons, GitHub-style marks, generic chat bubbles, generic M monograms, decorative flourishes, pseudo-text, misspelled text, any text besides “Markover”.

## 04 — Markdown terminal

![Markdown terminal identity board](./04-markdown-terminal.png)

### Rationale

This direction compresses an `M`, a closing bracket, a block-stop dot, and a
lime review slash into one constructed glyph. The clipped corners and coarse
geometry create terminal energy without drawing a literal terminal window. The
black app tile gives the lime slash maximum recognition at small sizes, while
the mono wordmark keeps the developer-tool positioning explicit.

### Generation prompt

> Use case: logo-brand
>
> Asset type: clean brand identity concept board for a coding-native Markdown review desktop application
>
> Primary request: Design one original ultra-minimal Markover identity with sharp terminal energy. Build an ownable abstract symbol from the visual grammar of Markdown syntax and code editing—combine the rhythm of an M, a slash, a block marker, bracket, or cursor into one unified glyph, but do not merely typeset raw characters. The mark should suggest Markdown blocks being reviewed, crossed, or handed off, with a precise one-bit / pixel-grid logic.
>
> Scene/backdrop: perfectly flat off-white presentation board, no environmental scene and no mockups.
>
> Subject: Show exactly three coordinated components with generous whitespace: (1) large standalone symbol, (2) horizontal lockup pairing the same symbol with the exact wordmark “Markover”, and (3) favicon/app-icon crop of the same symbol inside a simple square container. All repeated symbols must match exactly.
>
> Style/medium: pristine 2D flat vector-logo aesthetic; bespoke monospaced wordmark with measured terminal-like spacing; sharp rectilinear geometry, deliberately notched corners, hard pixel-grid alignment; current developer-tool identity but not retro arcade. No gradients, shadows, depth, glow, bevels, textures, or photorealism.
>
> Composition/framing: landscape identity board with three clear zones on a rigorous baseline grid; large mark at left, horizontal lockup across center, favicon specimen at right; no labels or annotations.
>
> Color palette: deep near-black, electric lime green, off-white only. Use lime as a strong but controlled signal color.
>
> Text (verbatim): “Markover” — render exactly once, spelled M-a-r-k-o-v-e-r, with no tagline and no other text.
>
> Constraints: flat vector-friendly shapes; extremely strong silhouette at 16 px; no hairlines or tiny details; symbol must feel drawn, constructed, and ownable rather than a font character; one coherent symbol repeated consistently; suitable for an Electron app icon and tiny favicon.
>
> Avoid: GitHub or Octocat resemblance, generic code brackets, generic `</>` icon, raw `#` or `M/` typed as text, checkmarks, terminal window illustrations, speech bubbles, eyes, stationery, devices, office mockups, paper mockups, UI screenshots, multiple competing logo options, pseudo-text, misspelled text, extra text besides “Markover”.
