Guide

Getting started

Markover turns Markdown into a navigable review surface and returns feedback as one structured artifact.

Install

Clone the repository and install its dependencies:

git clone https://github.com/lastobelus/markover.git
cd markover
npm install

Run Markover

Start the desktop application directly from the checkout:

npm start

Open a review

Give Markover a Markdown document and a short explanation of the feedback you need:

npm --silent run markover -- open ./document.md \
  --summary "Review the decisions before implementation."

The command starts Markover when necessary, opens the document in the review inbox and returns an opaque review ID.

Keep the review ID. It identifies the durable review when the agent retrieves the finished handoff.

Return the handoff

After the reviewer is finished, retrieve the complete frozen review:

npm --silent run markover -- get mko_8f3a2c

Markover returns one JSON object containing the source snapshot, document tree, annotations, attachments and review context.
